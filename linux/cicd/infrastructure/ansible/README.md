# Domowe laboratorium CI/CD

Repozytorium zawiera konfigurację infrastruktury laboratoryjnej zarządzanej przez Ansible.

## Główne komponenty

- GitLab CE
- GitLab Container Registry
- Jenkins Controller
- Jenkins Agent
- trzywęzłowy klaster K3s HA
- embedded etcd
- kube-vip
- MetalLB
- NGINX Ingress Controller
